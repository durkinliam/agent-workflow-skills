# Working records

Use repository conventions or one ignored `.agent/plans/<name>/PLAN.md`.
Small tasks can stay in chat. Keep research, decisions and the plan together;
link sources instead of copying transcripts.

Record outcome, constraints, evidence, design, steps, verification, authority,
destination, status and next action. Add issue records only for independently
verifiable slices needing separate contexts; reference the parent agreement.

Verified means checks support their claims. Complete also requires independent
review and the authorized destination. Keep unresolved questions explicit.
