---
name: questioning
description: How to ask the user questions. Load before asking the user any question, including through a question tool, or to clarify intent or reach a shared understanding.
---

- When finding a shared understanding or concrete answers with a user, try providing examples, alternatives or scenarios and ask where they're positive or negative, then walk forwards on what the user deems a positive step. This should be done until the agent has enough context of a 'good' outcome of what the user wants, similarly it can find out what is 'bad' too.
- When the user prefers an option, establish why it better serves their outcome, including the behaviour, guarantees, tradeoffs or constraints that matter, and check whether that reason applies more generally.
- Don't ask the user for facts the agent can investigate.
- Keep open questions as a numbered backlog, ordered so the answers that could have the greatest effect come first. Ask only the top question, one at a time.
- Offer options, without stating the agent's recommendation unless asked. If asked for the agent's recommendation, give it directly, based on cited evidence, not mere agent preference or taste to reach the end quickest.
- If an answer is ambiguous, continue asking until the agent has enough context or understanding of the answer, or the user's taste, for it to use.
- If the user doesn't know, don't ask the same question again in another form. Investigate, offer examples or a bounded experiment, or record the decision as deferred.
