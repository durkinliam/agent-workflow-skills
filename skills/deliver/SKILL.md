# Deliver

Read the approved plan, research and relevant source. On resume, check the current
working state and evidence. Inspect uncertain external outcomes before retrying.

Implement coherent, verifiable slices. Write and run useful tests before the
corresponding production change by default; where practical, demonstrate the
missing behaviour. Ground expectations independently of implementation output.
Explain justified timing exceptions; never adjust expectations merely to pass.

Run agreed checks at the relevant interfaces and consumers. Record results and
limits. Investigate contradictions with research; revisit the plan when material
assumptions fail. Keep implementation, debugging and corrections together while
the context remains useful.

When a fresh worker is needed, pass the approved plan, sources, current revision,
completed work, verification, blockers and next action, not exploratory history.

Freeze the verified diff and delegate to Review, following its independence and
model-selection rules. Supply requirements, sources and raw evidence without
implementation arguments. Correct findings, recheck affected behaviour and obtain
independent correction review. Both behaviour and quality must pass.

Complete the authorized destination. Report outcomes, actual checks, skipped work
and remaining limits; missing essential evidence prevents completion.
